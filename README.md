## 🗂️ Project Structure

> ⚡ True **single-page app** — one file, everything inline.

```
keshav-video-editor/
│
└── 📄 index.html   ← Entire site: markup, CSS animations & JS
                       (particles, matrix rain, typewriter, cursor trail)
                       all in ONE file. Zero dependencies.
```

## 🎬 Portfolio Categories

| Category | Description |
|----------|-------------|
| 💑 **Couple Edits** | Edits centered around couple moments |
| 🔤 **Typographic** | Text/kinetic-typography focused edits |
| 🎓 **Friendzone** | Scene from the "Campus Diary" series |
| 🌑 **Dark Humour** | Darker-tone edits (mature content flagged) |
| 🇮🇳 **Operation Sindoor** | Edit based on Operation Sindoor |
| 💃 **Velocity Edit** | Fast-cut dance edit |

Each card opens the corresponding **Google Drive** folder/file directly in a new tab.

```bash

git clone https://github.com/k4hav/keshav-video-editor.git
cd keshav-video-editor

# Just open it — no server, no build step
open index.html
```
